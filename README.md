# Simple Calculator

A simple calculator built using HTML, CSS, and JavaScript.

## Features

- Basic arithmetic operations (+, -, ×, ÷)
- Percentage calculation
- Clear & Backspace
- Modern UI
- Glassmorphism design
- Dark & Light mode

## Technologies
- HTML5
- CSS3
- JavaScript
